# MG S5 EV - บันทึกค่าชาร์จและคำนวณอัตราสิ้นเปลือง ⚡

เว็บแอพพลิเคชันบันทึกและคำนวณอัตราสิ้นเปลืองค่าชาร์จรถไฟฟ้า สำหรับ **MG S5 EV** ออกแบบให้ใช้งานง่าย กรอกสะดวกรวดเร็ว ทั้งบนคอมพิวเตอร์และมือถือ

---

## ⚡ อัปเดตล่าสุดตามความต้องการ:
1. **ตัดเมนูที่ไม่จำเป็นออก:**
   - นำตัวเลือก **"ชาร์จบ้าน"** ออก เน้นเฉพาะสถานีชาร์จสาธารณะ (PEA Volta, PTT EV Station PluZ, EA Anywhere, EleXA, Evolt, MG Super Charge ฯลฯ)
   - นำช่อง **"หมายเหตุ"** ออก ให้หน้าจอกระชับ คลีน และกรอกได้ไวที่สุด
2. **ช่องเลขไมล์ (Odometer):**
   - มีช่องเลขไมล์แสดงอยู่บนฟอร์มหลัก **(ไม่บังคับใส่ — ปล่อยว่างได้ 100%)**
3. **ระบบคำนวณอัตราสิ้นเปลืองอัตโนมัติ (บาท/กม.):**
   - **คำนวณได้ทันที!** เมื่อใส่จำนวนเงินที่ชาร์จ + เลขไมล์อย่างน้อย 2 ครั้ง
   - สูตรคำนวณ: `อัตราสิ้นเปลือง (บาท/กม.) = จำนวนเงินที่ชาร์จ ÷ (เลขไมล์ปัจจุบัน - เลขไมล์ครั้งก่อนหน้า)`
   - แสดงผลใน **การ์ดสรุปภาพรวมด้านบน** และ **แต่ละรายการในประวัติการชาร์จ** (เช่น `0.85 บาท/กม. (วิ่งไป 350 กม.)`)
   - มีระบบคำนวณเปรียบเทียบว่า **ประหยัดกว่ารถน้ำมันไปกี่บาทต่อกิโลเมตร** และสรุปยอดเงินที่ประหยัดได้รวม

## 🚀 วิธีเปิดใช้งาน

### วิธีที่ 1: ดับเบิ้ลคลิกไฟล์ (ง่ายที่สุดบน Windows)
- ดับเบิ้ลคลิกไฟล์ `start.bat`
- เบราว์เซอร์จะเปิดหน้าแอพ `http://localhost:3000` ให้อัตโนมัติ

### วิธีที่ 2: รันผ่าน Terminal / Command Prompt
```bash
npm start
```
หรือ
```bash
node server.js
```

### วิธีที่ 3: เปิดบนมือถือ (ขณะนั่งอยู่ในรถ MG S5)
- เชื่อมต่อมือถือเข้ากับ Wi-Fi วงเดียวกับคอมพิวเตอร์
- เปิดเบราว์เซอร์ในมือถือแล้วพิมพ์ URL ที่คอนโซลแจ้ง (เช่น `http://10.50.13.225:3000`)
- สามารถกด **"Add to Home Screen" (เพิ่มไปยังหน้าจอโฮม)** เพื่อใช้งานเหมือนแอพมือถือจริงได้ทันที
